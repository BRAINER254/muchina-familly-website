Muchina Family — Static Website

This is a ready-to-deploy static site scaffold for the Muchina family.

Contents:
- index.html — Home
- announcements.html — Announcements list
- entertainment.html — Photo gallery
- ideas.html — How to share ideas
- css/style.css — Styles
- js/main.js — Small interactivity

Deploy:
- GitHub Pages: Create a new repo, push these files to the repo root or gh-pages branch, then enable Pages in repo settings.
- Netlify: Drag & drop this folder or connect the repo; Netlify can also enable simple form handling if needed.

Next steps:
- Add real images to assets/images
- Replace the example email addresses
- (Optional) Initialize git, commit, and push to GitHub

To preview locally: open index.html in a browser.
